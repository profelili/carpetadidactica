📁 Restaurar Carpeta Didáctica

Guía para restaurar el repositorio y publicar el sitio

✅ Estado Actual

✓ El proyecto está completo y funcionando
Todos los archivos del proyecto están listos en este entorno y compilan correctamente.

El Pull Request #1 ya contiene todo el código del proyecto, pero fue cerrado sin fusionar.

🚀 Opción 1: Fusionar el PR (Más Rápido)

Esta es la forma más rápida de restaurar el repositorio:

  1. Andá a Pull Request #1
  2. Si está cerrado, buscá el botón "Reopen pull request" y tocalo
  3. Ahora debería aparecer el botón verde "Merge pull request"
  4. Tocá "Merge pull request" → "Confirm merge"
  5. Esperá 1-2 minutos
  6. Andá a Settings → Pages → Source: GitHub Actions
  7. Esperá a que el workflow termine con ✅
  8. Tu sitio estará en https://profelili.github.io/carpetadidactica
Ir al Pull Request #1

📦 Opción 2: Subir Manualmente

Si preferís subir los archivos manualmente o el PR no se puede reabrir:

⚠️ IMPORTANTE: Antes de subir, borrá los archivos viejos del repo (index.tar, static.yml, etc.)

Pasos:

  1. Descargá el proyecto desde este entorno (si hay botón de descarga disponible)
  2. Descomprimí el archivo en tu computadora
  3. Andá a tu repositorio en GitHub
  4. Borrá los archivos viejos: index.tar, static.yml (si existen)
  5. Hacé clic en Add file → Upload files
  6. Arrastrá TODO el contenido de la carpeta del proyecto:
    • La carpeta .github (¡muy importante!)
    • La carpeta src
    • Todos los archivos: index.html, package.json, README.md, etc.
  7. Hacé clic en Commit changes
  8. Andá a Settings → Pages → Source: GitHub Actions
  9. Esperá 1-2 minutos hasta que el workflow termine con ✅
  10. Tu sitio estará en https://profelili.github.io/carpetadidactica
